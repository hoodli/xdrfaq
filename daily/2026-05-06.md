## Nacos 密码修改后操作

**场景：** Ailpha XDR 环境中修改 Nacos 密码后，需要同步更新 ConfigMap，否则应用无法连接 Nacos。

**步骤：**

1. 修改 ConfigMap：
```
kubectl edit cm -n ailpha-xdr midware-env
```
2. 找到并更新变量：
```
NACOS_AUTH_IDENTITY_VALUE: <新密码>
```
3. 手动重启应用 pod 使配置生效

**关联：**
- AXDR V2.0R25C40 部署
- ailpha-xdr namespace 操作
