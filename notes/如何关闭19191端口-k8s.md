# 如何关闭19191端口-k8s



## 需求


关闭19191端口


## 步骤


删除19191
kubectl edit kafkaclusters.kafka.banzaicloud.io -n kafka kafka
#找到下面配置，删除配置，保存退出
    - accessMethod: NodePort
      containerPort: 9095
      externalStartingPort: 19191
      hostnameOverride: .kafka.svc.cluster.local
      name: epdn
      type: plaintext

kubectl delete svc -n kafka kafka-0-epdn
kubectl get svc -n kafka  | grep 19191
检查，如果上面命令没有输出，则证明端口已经关掉了
