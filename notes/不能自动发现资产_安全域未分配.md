# 不能自动发现资产/安全域未分配



## 适配版本


R25C21、R25C22


## 问题描述


已配置安全域，但日志里符合安全域范围的IP显示安全域未分配


## 原因


安全域未同步到redis


## 排查步骤


#查看redis密码
先进入mirror pod，这里的mirror用table建补全
kubectl exec -it -n ailpha-xdr mirror-5cf64c9589-wssbj bash
#获取redis密码：
env | grep REDIS
#登录到redis
kubectl -n redis exec -ti redis-node-0 bash
redis-cli
auth redis密码
select 6
key baas:*
get baas:复制securityzonemarker那行内容

如图则是安全域未写到redis。


## 解决步骤


登录mirror。手动再创建一个安全域，过几分钟后再去redis里查看是否已经有安全域信息。
