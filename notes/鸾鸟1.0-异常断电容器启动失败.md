# 鸾鸟1.0-异常断电容器启动失败



## 适配版本


R23C10


## 问题现象


parent directory /usr/hdp/current/hadoop-client/conf doesn't exist


## 解决步骤


第一台机器上执行

docker-compose -f /opt/ailpha-install/docker-compose/docker-compose-master.yml down
docker-compose -f /opt/ailpha-install/docker-compose/docker-compose-node.yml down
rm -rf /data/ambari-postgresql/
#如没有ambari-postgresql，则跳过此步
docker-compose -f /opt/ailpha-install/docker-compose/docker-compose-master.yml up -d
#等待ambari能正常打开 登录密码是 admin/admin
docker-compose -f /opt/ailpha-install/docker-compose/docker-compose-node.yml up -d

比较一下两个数字是否一致

cat /opt/ailpha-install/cluster_init/hostinfo-ansible.json | grep ip | wc -l
curl -H "X-Requested-By: ambari" -X GET -u 'admin:admin' http://localhost:18080/api/v1/hosts | grep host_name | wc -l

执行下面命令

curl -H "X-Requested-By: ambari" -X POST -u 'admin:admin' http://localhost:18080/api/v1/stacks/HDP/versions/3.1/operating_systems/redhat7/repositories/HDP-3.1?validate_only=true -d @/opt/ailpha-install/cluster_init/hdp.json
curl -H "X-Requested-By: ambari" -X POST -u 'admin:admin' http://localhost:18080/api/v1/stacks/HDP/versions/3.1/operating_systems/redhat7/repositories/HDP-UTILS-1.1.0.22?validate_only=true -d @/opt/ailpha-install/cluster_init/hdp-util.json
curl -H "X-Requested-By: ambari" -X POST -u 'admin:admin' http://localhost:18080/api/v1/stacks/HDP/versions/3.1/repository_versions/ -d @/opt/ailpha-install/cluster_init/repoversion.json
curl -H "X-Requested-By: ambari" -X POST -u 'admin:admin' http://localhost:18080/api/v1/blueprints/bigdata-hdp -d @/opt/ailpha-install/cluster_init/blueprint.json
curl -H "X-Requested-By: ambari" -X POST -u 'admin:admin' http://localhost:18080/api/v1/clusters/bigdata -d @/opt/ailpha-install/cluster_init/hostmapping.json

等 ambari界面上 都绿了就好了
